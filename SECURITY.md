# Security

Chat On Steroids runs on the user's own Windows computer and can bridge ChatGPT requests to local tooling. Treat terminal commands, local files, session records, connected accounts, and browser permissions as sensitive.

The Companion extension can access supported ChatGPT web pages and communicates with the local COS process. Review permissions before enabling it.

Use only published release archives whose SHA-256 values match the release notes. Do not run older app and new app copies simultaneously.

Back up existing session data before changing installations. Do not post credentials, access tokens, session logs, private keys, or license-issuer signing materials in public GitHub issues.

Once this repository is live, report security vulnerabilities privately using GitHub's private vulnerability reporting feature if it is enabled. If it is not available, contact the repository maintainer through a private channel.

This repository is intended for binary releases and documentation, not publication of the developer's private source tree or license signing keys.
